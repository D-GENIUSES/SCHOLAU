What is a Computer?
Deﬁnition: A computer is an electronic device that:
● T akes data as input
● Processes the data under the control of a program (set of instructions)
● Produces an output
● The entire system is called a computer system

Early Milestones in Computing (1801 - 1937)
● 1801: Joseph Marie Jacquard’s loom uses punch cards for weaving fabric 
designs
● 1822: Charles Babbage conceives the ﬁrst steam-driven calculating machine 
(though incomplete)
● 1890: Herman Hollerith develops a punch card system to calculate the U.S. 
Census
● 1936: Alan Turing presents the concept of a universal computing machine 
(Turing Machine)
5

--- page 6 ---
Mid-20th Century Developments (1939 - 1958)
● 1941: Atanasoff and Clifford Berry create a computer with memory for 
simultaneous equation solving
● 1943-1944: ENIAC, the ﬁrst large-scale digital computer, is built by 
Pennsylvania professors, John Mauchly and J. Presper Eckert
● 1946: UNIVAC by John Mauchly and J. Presper Eckert becomes the ﬁrst 
commercial computer for government/business use
● 1953-1958: Grace Hopper develops COBOL, and the integrated circuit 
(computer chip) is invented

Personal Computers & Major Inventions (1964 - 1981)
● 1964: Douglas Engelbart invents the computer mouse and GUI
● 1969: UNIX operating system developed
● 1971: Alan Shugart invents the ﬂoppy disk

Characteristics of the computer system
● Speed: Performs millions of instructions per second, operating in microseconds or 
nanoseconds
● Accuracy: Executes calculations with 100% precision, errors occur only with 
inconsistent or inaccurate data
● Diligence: Maintains consistent performance without fatigue, capable of millions of 
operations with accuracy
● Versatility: Can handle a variety of tasks with equal accuracy and efﬁciency
● Reliability: Produces consistent results for the same input every time
● Automation: Operates tasks automatically without the need for manual 
intervention
● Memory: Stores data in primary (built-in) and secondary (removable) storage 
devices like CDs and pen drives

Data and Information
● Data:
Data  is a collection of unorganized facts & ﬁgures and does not provide any further 
information regarding patterns, context, etc. Hence data means "unstructured 
facts and ﬁgures" .
● Information: 
Information is structured data i.e. organized, meaningful and processed data. T o 
process the data and convert into information, a computer is used.

Functions of Computers
● Receiving Input:
○ Data is fed into computer through various input devices like keyboard, mouse, digital 
pens, etc. 
○ Input can also be fed through devices like CD-ROM, pen drive, scanner, etc.
● Processing the information
○ Operations on the input data are carried out based on the instructions provided in the 
programs.
● Storing the information
○ After processing, the information gets stored in the primary or secondary storage 
area.
● Producing output
○ The processed information and other details are communicated through output 
devices like monitor, printer, etc

Central Processing Unit (CPU)
● Deﬁnition: The "brain" of the computer that controls operations of all parts
● Components:
○ Arithmetic Logic Unit (ALU):
■ Processes data, performs calculations, and comparisons
■ Non-numeric processing and decision-making occur here
○ Control Unit:
■ Extracts instructions and directs CPU operations
■ Supervises data ﬂow within the CPU
14

--- page 15 ---
Functions of the Control Unit
● Controls all activities of the computer.
● Supervises and directs the ﬂow of data within the CPU.
● Transfers data to the ALU and results to memory.
● Fetches results from memory to output devices.
Memory Unit
● Deﬁnition: Stores data, instructions, and results
● Types: Primary and Secondary
● Unit of Memory: Byte (1 Byte = 8 Bits).

Primary Memory
● Deﬁnition: Main memory present on the motherboard
● Types:
○ Random Access Memory (RAM):
■ Volatile, temporary storage
■ Data is lost when powered off
■ Types: Static RAM (SRAM), Dynamic RAM (DRAM)
○ Read Only Memory (ROM):
■ Non-volatile, permanent storage
■ Data remains when powered off
■ Types: PROM, EPROM, EEPROM, Flash memory

RAM vs. ROM
Feature RAM ROM
Volatility Volatile (temporary) Non-volatile (permanent)
Data Loss Lost when power is off Retained when powered off
Storage Capacity Small capacity High capacity
Processing Speed High speed Low speed
User-deﬁned Yes (modiﬁable) No (read-only)

● Analog Computers: Measure physical quantities; now nearly extinct
● Digital Computers: Use binary (0 and 1), programmable, suitable for 
complex computations
● Hybrid Computers: Combine analog and digital functionalities for process 
control

Types of Computers (Based on Size and Processing 
Power)
● Microcomputers: Uses microprocessor as CPU; also called personal computers 
(PCs)
○ Smaller in size
○ Input: Keyboard, mouse
○ Output: Monitor
○ Examples: Desktops, laptops, notebooks, tablets, Personal Digital Assistants (PDAs)
● Minicomputers: Multi-user computers supporting 10 to 100 users 
simultaneously.
○ Positioning: Intermediate in size and processing capacity between microcomputers 
and mainframes.
○ Use: Mid-range systems or workstations for businesses and organizations
22

--- page 23 ---
● Super Mini Computers: 32-bit word length, Memory: 1 M byte to 8 M 
bytes, Speed: Nearly 2 million instructions per second
○ Applications: Research, development, process control in commercial 
organizations.
● Mainframe Computers: Powerful multi-user computers, capable of 
supporting 100 to 1000+ users simultaneously
○ Applications: Used in large organizations for processing bulk data and critical

● Supercomputers: Extremely fast computers capable of hundreds of

Concept of Hardware and Software
● Hardware: Physical components of a computer system including the:
○ Input Devices: Keyboard, Mouse, Joystick, Scanner
○ Processing Devices: CPU, Memory
○ Storage Devices: Floppy Disk, Hard Disk, CD-ROM, T ape Drive, Zip Drive
○ Output Devices: Monitor, Printer, Sound Card, Modem
● Software: Set of instructions (programs) that control hardware operations
○ Applications Software: Programs for speciﬁc tasks like word processing, 
spreadsheets, database management, and presentations. E.g. MS Word, Excel, 
PowerPoint, MySQL
○ Systems Software: The operating system and utilities that manage hardware and 
enable other programs to run. E.g. Windows, Linux, macOS

Functions of an Operating System
● Booting the Computer: Initializes hardware and allows the system to start
● User Interface: Provides Command Line or Graphical User Interface (CLI or 
GUI)
● Hardware Management: Controls and manages hardware resources
● File System Management: Organizes and maintains ﬁles on the disk
● Program Support: Provides services like saving/loading ﬁles, memory 
allocation, etc

--- page 26 ---
Categories of Operating Systems
● Multitasking Operating System:
○ Cooperative Multitasking: Requires cooperation between OS and applications 
(e.g., Macintosh OS)
○ Preemptive Multitasking: OS controls CPU time and priority (e.g., UNIX, 
Windows NT)
● Multi-user Operating System:
○ Supports multiple users at the same time (e.g., UNIX, Windows NT)
● Multiprocessing Operating System:
○ Asymmetric: One CPU controls others
○ Symmetric: No single controlling CPU, all CPUs work independently.

Types of Operating Systems
● DOS (Disk Operating System): Command-line based, popular on Intel PCs
● Microsoft Windows: GUI-based, runs DOS and Windows programs
● OS/2: IBM/Microsoft OS for Intel processors, multitasking capabilities
● Macintosh OS: Purely graphical, easy-to-use, ideal for desktop publishing
● UNIX: Multi-platform, robust, command-line-based, widely used
● Windows NT: 32-bit OS, multitasking, supports Windows and some UNIX

Overview of the Internet
● Deﬁnition: A global network of computers that communicate seamlessly
● Origins: Began with ARPANET in the 1960s by the U.S. Department of 
Defense
● Connection: Networks worldwide communicate using Transmission 
Control Protocol/Internet Protocol (TCP/IP)
● How Information is Transmitted on the Internet:
○ Data is broken into packets for transmission.
○ TCP/IP ensures proper delivery of these packets across networks.
