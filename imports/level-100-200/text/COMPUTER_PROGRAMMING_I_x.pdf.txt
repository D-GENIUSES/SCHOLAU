1.1 What is Computer Programming? 
Computer programming is the process of giving a computer a set of instructions that tells it 
what to do and how to do it. 
For example, suppose we want a computer to calculate the average of three examination 
scores. 
A human being may think: 
1. Get the three scores.  
2. Add them together.  
3. Divide the result by 3.  
4. Display the answer.  
A computer cannot simply understand these instructions in ordinary English. They must be 
converted into a programming language. 
1.2 What is a Programming Language? 
A programming language is a formal language used to communicate instructions to a 
computer. 
Examples include: 
• Java  
• Python  
• C  
• C++  
• JavaScript  
• C#  
• Kotlin  
• PHP  
Different programming languages have different syntax and features, but they generally allow 
programmers to: 
• store information  
• perform calculations  
• make decisions  
• repeat operations  

--- page 2 ---
• process data  
• communicate with users  
• interact with files and databases.  
1.3 Why Java? 
Java is a general purpose, object oriented programming language widely used for developing 
different types of software. 
Java is useful for students because it introduces important programming concepts that are 
applicable to many other languages. 
Important characteristics of Java 
Java is: 
• object oriented  
• strongly typed  
• platform independent through the Java Virtual Machine  
• relatively portable  
• widely used  
• supported by a large standard library.  
The common Java principle is: 
Write Once, Run Anywhere 
This means that compiled Java programs can run on systems that have a compatible Java 
Virtual Machine.

PROGRAMMING PARADIGMS 
A programming paradigm is a particular way of thinking about and organising a program. 
The course introduces four important paradigms. 
 
2.1 Functional Programming 
Functional programming treats computation largely in terms of functions. 
A function receives input and produces an output. 
2.2 Declarative Programming 
Declarative programming focuses more on what should be achieved than on specifying 
every step of how to achieve it. 
2.3 Logic Programming 
Logic programming represents problems using facts and rules. 
Languages such as Prolog are associated with this paradigm. 
2.4 Object Oriented Programming 
Object oriented programming, or OOP, organises software around objects and classes. 

--- page 4 ---
Java is primarily an object-oriented language. 
Important OOP concepts include: 
• class  
• object  
• abstraction  
• encapsulation  
• inheritance  
• polymorphism.  
2.5 Scripting Languages 
A scripting language is commonly used to automate tasks or control applications. 
Examples include: 
• JavaScript  
• Python  
• PHP  
• PowerShell  
• Bash.  
Java can also be used for scripting like tasks, although Java is traditionally regarded as a 
general purpose compiled language.

Polymorphism means one interface or reference can be associated with different forms of

Consider:

    void sound() { 
        System.out.println("Animal makes a sound"); 
    } 
} 
Subclass: 
class Dog extends Animal { 
 
    @Override 

--- page 24 ---
    void sound() { 
        System.out.println("Dog barks"); 
    } 
} 
Another subclass: 
class Cat extends Animal { 
 
    @Override 
    void sound() { 
        System.out.println("Cat meows");

SEARCHING ALGORITHMS 
Searching means finding a particular value in a collection. 
Suppose: 
10  25  30  45  60 
We want to find 45. 
 
14.1 Linear Search 
Linear search examines elements one after another. 
static int linearSearch(int[] data, int target) { 
 

--- page 25 ---
    for (int i = 0; i < data.length; i++) { 
 
        if (data[i] == target) { 
            return i; 
        } 
    } 
 
    return -1; 
} 
If the target is found, the index is returned. 
If it is not found: 
-1 
 
14.2 Practical Example 
int[] numbers = {10, 25, 30, 45, 60}; 
 
int result = linearSearch(numbers, 45); 
 
if (result != -1) { 
    System.out.println("Found at index " + result); 
} else { 
    System.out.println("Not found"); 
} 
 
14.3 Binary Search 
Binary search is applicable to a sorted collection. 
Example: 
10 20 30 40 50 60 70 
To find 60, instead of checking every item, the algorithm repeatedly divides the search area. 
Basic idea: 
Search entire array 
       ↓ 
Check middle 
       ↓ 
Target smaller or larger? 
       ↓ 
Discard irrelevant half 
       ↓ 
Repeat 
Binary search has logarithmic time complexity, commonly expressed as: 

--- page 26 ---
O(log n)

15.1 Bubble Sort 
Bubble sort repeatedly compares neighbouring elements. 
static void bubbleSort(int[] data) { 
 
    for (int i = 0; i < data.length - 1; i++) { 
 
        for (int j = 0; j < data.length - 1 - i; j++) { 
 
            if (data[j] > data[j + 1]) { 
 
                int temp = data[j]; 
                data[j] = data[j + 1]; 
                data[j + 1] = temp; 
            } 
        } 
    } 
}
